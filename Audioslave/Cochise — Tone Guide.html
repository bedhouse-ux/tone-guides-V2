Tone Guide

Cochise

Audioslave — Audioslave (2002)
Key: E minor pentatonic Rig: Digital — Kemper Player + FR-10 Feel: Aggressive, riff-driven hard rock

The Reference Point

Morello's Cochise tone is overdrive into a cranked Marshall JCM800, not a fuzz-driven sound. The song's signature moments are specific: a helicopter-effect intro built from percussive picking-hand technique through a short slapback delay with a DigiTech Whammy pedal rocked for the oscillating pitch warble, a brief solo using an EQ pedal boost plus more Whammy octave-drops, and an MXR-style phaser on the bridge. There's no pitch-shift pedal or phaser anywhere in the current collection, so this build nails the riff and rhythm tone but can't reproduce those two specific effects — flagged honestly below rather than faked.

Morello's actual Audioslave-era guitar ("Soul Power," a modified Fender Aerodyne Strat) runs Fender Noiseless single-coils in neck/middle and a Seymour Duncan Hotrails rail humbucker in the bridge — a hybrid that's mostly single-coil voiced with a hot humbucker option. This 2016 McCarty's coil-split gets you the same basic functional move on one guitar: full humbucker output here for the riff's push, with the split available if you want a thinner, more single-coil-like texture anywhere else in the song. Bridge humbucker, wide open, for the main riff and chorus.

The 385 comes off the board and sits in front of the Kemper's input, same hybrid logic as the Kravitz build — physical pedal for the main drive character, Kemper for everything the analog board can't do. The Warm Bender isn't used here at all: the documented tone is overdrive-into-JCM800, not fuzz, so reaching for it would push this away from the actual record rather than toward it.

Same logic that worked for Immigrant Song's cranked-Marshall character — 385+ voicing adds the extra gain stage for a thicker, more compressed saturation that reads as a pushed British stack rather than a stompbox. Gain set fairly high for real crunch and sustain on the riff's palm-muted chugs and power chords. Channel A carries the main sound; Channel B is free if you want an easy footswitch jump to a hotter setting for the chorus.

Kemper Player — Effects

Helicopter Intro / Solo

Pedal Pitch

This is the closest available substitute for the DigiTech Whammy work on the record. Assign to the expression pedal or a footswitch for octave-up/down shifts. For the intro's oscillating warble, rock the assigned control back and forth in time with the percussive picking-hand strikes on the muted strings. For the solo's octave-down dips, set for a full octave drop and engage on the specific notes rather than holding it through the whole phrase.

Bridge

Phaser (onboard effects slot)

Same flagged gap as the Kravitz build — worth confirming in Rig Manager whether your Kemper's stock effects include a baseline Phaser module before the session. If present, moderate rate and depth for the bridge section only. If not, this is an honest gap rather than something to substitute with the Brigade's chorus/vibrato, which won't give the same swept-notch character.

Solo Boost

EB-10-style Boost

The documented solo uses an EQ pedal purely for a volume lift, not a tone change — mirror that with a clean level boost on the Kemper's own boost/EQ effect slot rather than reaching for anything that reshapes the frequency curve. Same role the physical EB-10 played for the Immigrant Song solo, just handled digitally here since the EB-10 itself lives on the Clapp 15's loop.

Profile choice: a cranked Marshall JCM800-style profile is the documented target — a different amp family from the plexi-leaning Kravitz build, more modern and higher-gain in character.
